# Dragon Language Proposals

This directory contains language evolution proposals for the Dragon programming language.

## Proposal Process

1. **Discussion**: Ideas are discussed in the community
2. **Draft Proposal**: A formal proposal is written using the template
3. **Review**: The proposal is reviewed by maintainers and contributors
4. **Decision**: The proposal is accepted, implemented, rejected, or deferred
5. **Implementation**: Accepted proposals are implemented
6. **Release**: Implemented proposals are released in a version

## Proposal States

- **Draft**: Initial proposal under discussion
- **Accepted**: Approved for implementation
- **Implemented**: Implemented in the reference implementation
- **Rejected**: Not approved for implementation
- **Deferred**: Postponed for future consideration

## Directory Structure

- `accepted/` - Proposals that have been accepted but not yet implemented
- `implemented/` - Proposals that have been implemented in a release
- `rejected/` - Proposals that were not approved
- `deferred/` - Proposals postponed for future consideration

## Using the Template

Copy `PROPOSAL_TEMPLATE.md` to a new file in the appropriate directory and fill in the sections.
