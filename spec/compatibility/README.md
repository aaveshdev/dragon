# Dragon Language Compatibility

This directory contains specifications related to versioning, compatibility policies, and breaking changes.

## Files

- `versioning.md` - Semantic versioning and release numbering
- `compatibility-policy.md` - Guarantees about backward and forward compatibility
- `breaking-changes.md` - Documented breaking changes between versions
- `deprecations.md` - Deprecated features and removal timeline

## Source of Truth

The compatibility specification defines how Dragon manages evolution while minimizing disruption to users. Where the specification is incomplete or marked as implementation-defined, refer to the reference implementation and release notes for current behavior.
