# Dragon Language Specification - Language

This directory contains the specification of the Dragon programming language syntax and semantics.

## Files

- `lexical-structure.md` - Lexical structure, tokens, and formatting
- `syntax.md` - Overall grammar and syntactic structure
- `identifiers.md` - Rules for identifiers and naming
- `literals.md` - Literal values for different types
- `expressions.md` - Expression syntax and evaluation
- `statements.md` - Statement syntax and execution
- `variables.md` - Variable declaration and scoping
- `functions.md` - Function definition and invocation
- `closures.md` - Closure semantics and capture
- `classes.md` - Class definition and object-oriented features
- `inheritance.md` - Inheritance mechanisms and polymorphism
- `modules.md` - Module system and organization
- `imports.md` - Importing and exporting between modules
- `exceptions.md` - Exception handling and error propagation
- `concurrency.md` - Concurrency primitives and parallel execution
- `async.md` - Asynchronous programming model
- `execution-model.md` - Overall execution model and evaluation strategy

## Status

Where something is not yet formally specified, it is marked as:
- `Status: Unspecified` - No decision has been made.
- `Status: Implementation-defined` - The behavior is defined by the current implementation but may change in the future.
