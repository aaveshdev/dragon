## Becoming a Maintainer

Maintainership is granted by existing maintainers based on:
- Sustained high-quality contributions to the project
- Demonstrated understanding of the project's goals and values
- Ability to review code and provide constructive feedback
- Commitment to the project's long-term success

To express interest in becoming a maintainer, please contact the current maintainers through GitHub.

## Responsibilities

Maintainers are expected to:

1. **Review Contributions**: Timely review of pull requests and issues
2. **Guide Technical Direction**: Help shape the future of the language and implementation
3. **Manage Releases**: Coordinate and perform releases according to the release schedule
4. **Enforce Standards**: Ensure adherence to the code of conduct and contribution guidelines
5. **Mentor Contributors**: Help new contributors become productive members of the community
6. **Represent the Project**: Act as ambassadors for Dragon in the wider community

## Contact

For questions about project maintenance or to report issues with maintainer conduct, please contact the maintainers through GitHub or project communication channels.
